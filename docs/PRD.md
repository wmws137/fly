## 1. 项目概述

### 1.1 项目定位

一款 **2D 物理弹射休闲游戏**。玩家开局**蓄力弹射一次**确定初始轨迹，随后在飞行中靠**向量蹬风**和**背包道具**微调、续飞，直到落回低处或坠入虚空，以**最大飞行高度（丈）**计分。

### 1.2 游戏类型与标签

- **类型**：2D 物理弹射休闲 / 竖屏单段飞行
- **标签**：物理抛射、国风热梗、魔性洗脑、极限微操、碎片化时间

### 1.3 一句话简介

蓄力起飞，空中蹬风，道具续飞，看你能飞多高。

### 1.4 玩法分层（v0.6 核心）

| 层级 | 内容 | 权重 |
|---|---|---|
| **开场** | 蓄力 + 瞄准 + 一次弹射 | 决定起点，约占乐趣 30% |
| **主玩法** | 空中蹬风微操 + 3 格道具拾取/手动释放 | 占乐趣 **70%** |
| **目标** | 最大化飞行高度（丈） | 记分驱动复玩 |

### 1.5 交付形态

- 单页 `index.html` + Canvas 游戏循环
- 静态资源，无需后端
- 部署至 GitHub Pages：`https://<user>.github.io/fly/`
- 浏览器打开即玩，零安装

### 1.6 与原版设计文档的差异

| 维度 | 原设计文档 | **v0.6（当前）** |
|---|---|---|
| 单局结构 | 一次发射飞到底 | **一次发射飞到底**（回归） |
| 弹射角色 | 核心全程 | **开场定轨迹**，主玩法在蹬风/道具 |
| 道具 | 碰撞即生效 | **3 格背包，手动使用** |
| 计分 | 横向「里」 | 最大高度「丈」 |
| 屏幕 | 竖屏横飞 | 竖屏斜向上飞 |
| 蓄力角度 | 固定向右上 | 松手定角 45°～135° |

## 2. 核心玩法分析

### 2.1 核心体验

1. **开场弹射**：一次蓄力定初始轨迹（力度 + 角度）
2. **空中主玩法**：蹬风微操 + 道具策略（拾取、存包、择机释放）
3. **物理手感**：非对称重力轻功滞空
4. **高度追求**：最大高度（丈）驱动复玩

### 2.2 核心玩法循环（v0.6）

```
起跳台蓄力 → 一次弹射 → 飞行中蹬风/拾取/使用道具 → 落低处/虚空 → 结算 → 重开
```

| 阶段 | 玩家行为 | 系统响应 |
|---|---|---|
| 开局蓄力 | 起跳台长按蓄力 | 仅开局一次；蓄力条 + 瞄准线 |
| 发射 | 松手 / 松空格 | 进入 `flying`；**本局不可再蓄力** |
| 飞行 | 蹬风 + 拾取 + 使用道具 | 非对称重力；更新最大高度 |
| 道具 | 碰撞 | 自动入包（3 格满则忽略） |
| 使用 | 点击槽位 / 1·2·3 | 消耗道具，触发 Buff |
| 结算 | 落回低处或虚空 | 显示最大高度；0.5s 后可重开 |

### 2.3 弹射的定位（已确认）

| 问题 | 答案 |
|---|---|
| 需要分段飞行吗？ | **不需要**。一局只有 **1 段**完整飞行 |
| 弹射是玩法核心吗？ | **是开场，不是全程核心**。射出后主要靠蹬风 + 道具 |
| 为何保留弹射？ | 提供初始速度/角度变量；保留「起飞」仪式感与操作深度 |

### 2.4 胜负与计分

- **结算触发**：Y 回落到起跳高度以下并触地 / 坠入关卡底部虚空
- **成绩** = 本局**最大高度**（丈）
- **最高分**：`localStorage` 可选持久化

## 3. 物理与操作机制

### 3.1 物理参数（默认值，可 `@export` 调整）

| 参数 | 默认值 | 说明 |
|---|---|---|
| 逻辑分辨率 | 360×640 (9:16) | Canvas 内部坐标；PC 浏览器 letterbox 居中 |
| 基础重力 g | 980 px/s² | |
| 上升重力系数 | 0.6 | vy < 0 时 |
| 下落重力系数 | 1.2 | vy > 0 时 |
| 蓄力最大时长 | 2.0s | 满蓄对应最大初速 |
| 最小初速 | 200 px/s | 刚触发射阈值 |
| 最大初速 | 600 px/s | 满蓄 |
| 角度范围 | 45°～135° | 向上扇区（数学角，0°=右，90°=上），禁止向下/平射 |
| 蹬风基础冲量 | 180 px/s | 每 tick 标量大小 \|M\| |
| 蹬风间隔 | 0.15s | 持续滚/滑时每间隔施加一次 |
| 允许角度范围（蹬风 θ） | 0°～180° | 右→上→左；禁止向下分量 |
| 空气摩擦 | 0.92 / frame | 水平速度衰减 |
| 基础终端下落速度 | 800 px/s | 初始最大 vy（向下） |
| 下落加速率 | 40 px/s² | 飞行时间越长，终端下落速度上限越高 |
| 终端下落速度上限 | 1400 px/s | 终端 vy 封顶 |
| 上蹬风禁用阈值 | 终端 vy × 95% | 接近终端下落速度时禁止上蹬风 |

### 3.2 蓄力与发射（双参数分离）

**力度（速度大小）**——由按住时长决定：

```
speed = minSpeed + (maxSpeed - minSpeed) × clamp(holdTime / maxHoldTime, 0, 1)
```

**方向（角度）**——由松手/释放时指针位置决定：

```
rawAngle = atan2(-(releaseY - playerY), releaseX - playerX)  // Canvas Y 轴向下，取反
angle    = clamp(rawAngle, 45°, 135°)   // 向上扇区
vx = speed × cos(angle)
vy = -speed × sin(angle)   // Canvas Y 轴向下为正，向上取负
```

**视觉反馈**：

- 蓄力条三段：青（0～33%）、黄（33～66%）、红（66～100%）
- 蓄力中显示**瞄准辅助线**：从角色指向当前指针位置
- 脚下太极阵（占位：旋转圆环）速度随蓄力增加

### 3.3 蹬风系统概述

蹬风是飞行中的**主操作**。根据滚轮或滑动的**实际方向角**，将冲量分解为水平 + 垂直分量施加（例如左上 45° → 左、上各约 70.7%）。**不允许向下分量**；接近终端下落速度时**禁用向上分量**。

### 3.4 蹬风详细规范

#### 3.4.1 向量分解（核心）

每次蹬风 tick 施加标量冲量 `M = 180 px/s`，方向角 `θ`（数学坐标：0°=右，90°=上，180°=左）：

```
vx += M × cos(θ)
vy += -M × sin(θ)    // Canvas Y 向下为正，故取负
```

**示例**（M = 180）：

| 方向 | θ | vx 增量 | vy 增量（负=向上） |
|---|---|---|---|
| 纯右 | 0° | +180 | 0 |
| 右上 45° | 45° | +127 | −127 |
| 纯上 | 90° | 0 | −180 |
| **左上 45°** | **135°** | **−127** | **−127** |
| 纯左 | 180° | −180 | 0 |

#### 3.4.2 方向角来源

**滚轮 / 触控板**（PC）：

```
rawDx = deltaX
rawDy = -deltaY          // 滚轮向上 → rawDy > 0
if |rawDx| + |rawDy| < ε: 忽略

// 屏蔽向下：rawDy < 0 时不允许向上方半球外的输入
if rawDy < 0:
  if |rawDx| < ε: 整次忽略（纯向下滚）
  else: rawDy = 0       // 有水平分量则投影到水平（θ=0 或 180）

θ = atan2(rawDy, rawDx)
θ = clamp(θ, 0, π)      // 限定在上半平面（右→上→左）
```

**滑动手势**（移动端）：

```
rawDx = touchDeltaX
rawDy = -touchDeltaY    // 手指向上滑 → rawDy > 0
// 同上：屏蔽向下、clamp θ ∈ [0, π]
```

**键盘 fallback**（离散角，无滚轮时）：

| 按键 | θ |
|---|---|
| D / → | 0° |
| W+D / 右上 | 45° |
| W / ↑ | 90° |
| W+A / 左上 | 135° |
| A / ← | 180° |

按住连发，仍每 0.15s 施加一次。

#### 3.4.3 持续触发

| 规则 | 说明 |
|---|---|
| 模式 | 滚/滑过程中每 **0.15s** 按**当前 θ** 施加一次向量冲量 |
| 方向更新 | 每次 wheel/touchmove 更新 θ；连发期间用最新 θ |
| 停止 | 距上次输入 **> 100ms** 停止连发 |
| 空气摩擦 | 每帧 `vx *= 0.92`（仅水平） |

#### 3.4.4 终端下落速度与向上分量

```
terminalVy = min(800 + fallTime × 40, 1400)   // px/s，向下为正
```

| 条件 | 行为 |
|---|---|
| `vy < terminalVy × 0.95` | 完整向量蹬风（含向上分量） |
| `vy ≥ terminalVy × 0.95` | **剥离向上分量**：`vy += -M×sin(θ)` 不生效，仅保留 `vx += M×cos(θ)` |
| 视觉 | 有向上分量被禁时，箭头缺省上半截 / 变灰 |

#### 3.4.5 与 Buff 交互

| Buff | 垂直分量 | 水平分量 |
|---|---|---|
| 筋斗云 | 禁用（Buff 接管） | 可用 |
| 窜天猴 | 禁用 | 可用 |
| 无 Buff | 可用（受终端限制） | 可用 |

#### 3.4.6 视觉反馈

- 角色旁箭头指向当前 **θ**（长度 ∝ M），0.2s
- 持续蹬风：箭头方向随 θ 实时更新
- v1 无音效

#### 3.4.7 操作区（360×640，flying 态）

| 区域 | 范围 | 用途 |
|---|---|---|
| 蹬风区 | x∈[0,360), y∈[427,640) 扣除背包 | 滚轮 / 滑动手势 → **连续 θ** |
| 背包 | x∈[120,240), y∈[533,600) | 道具槽，不触发蹬风 |

> 不再划分离散左/上/右子区；方向由**输入向量角度**决定。  
> `ready` 态：底部中央蓄力，蹬风无效。Canvas 需 `preventDefault` 捕获 wheel。

### 3.5 碰撞检测

- 角色：**圆形**碰撞体（半径 ≈ 12px）
- **起跳台**：底部固定；**仅此处可蓄力**（开局一次）
- 道具：飞行中碰撞 → 尝试入包
- **地面/低处**：Y 回到起跳高度以下并接触 → 结算
- **虚空**：关卡底部以下 → 结算

## 4. 输入系统

### 4.1 输入映射

| 操作 | 移动端 | PC 鼠标 | PC 键盘 |
|---|---|---|---|
| 蓄力（仅 ready） | 底部中央长按 | 左键按住中央 | 空格按住 |
| 发射 | 松手 | 左键松开 | 空格松开 |
| 蹬风 | 滚/滑方向 → θ；`vx+=M·cosθ`，`vy+=−M·sinθ`；持续每 0.15s | 同左 | 离散角 W/A/D；按住连发 |
| 使用道具 | 点击槽位 | 点击槽位 | **1** / **2** / **3** |
| 重开 | 点击任意 | 同左 | Enter / 空格 |

> **向下滚/滑**：忽略或投影到水平。  
> **斜向**（如左上 45°）：左、上分量按 cos/sin 比例同时生效。

### 4.2 PC 操作说明

- 飞行中在 Canvas 上 **滚轮**（含触控板双轴滚动）→ 方向角 θ 连续变化
- 键盘 W/A/D 为 90°/180°/0° 等离散角 fallback，按住连发
- 斜滚时自动分解：例 135° → 左 127 + 上 127（M=180）

### 4.3 移动端操作说明

- 底部蹬风区 **滑动**，向量角 θ 同滚轮逻辑
- 屏蔽向下滑动；斜滑（如左上）按比例分解

### 4.4 触控布局（9:16 竖屏）

| UI 区域 | 位置 | 内容 |
|---|---|---|
| 高度 HUD | 左上角 | 当前高度 + 本局最高（丈） |
| Buff HUD | 右上角 | 已激活 Buff 倒计时 |
| 道具背包 | 底部中央上方 | 3 槽位；flying 时可点 |
| 操作安全区 | 底部 1/3（除背包） | 滚/滑 → 连续角度 θ |
| 蓄力区 | 底部中央 | **仅开局 ready 态**可蓄力 |

### 4.5 防误触

- 进入结算态后 **0.5 秒内**忽略所有重开输入
- 避免手滑在结算瞬间误触开始下一局

### 4.6 性能要求

- 触控/鼠标/键盘输入延迟目标 **< 50ms**
- 移动端强制竖屏 Portrait；PC letterbox 展示 9:16 画布

## 5. 道具、背包与 Buff 系统

### 5.1 设计原则

- **拾取与使用分离**：碰到道具 ≠ 立即生效，先入背包，由玩家决定何时使用
- **契合单段飞行**：开局弹射定方向，飞行中拾取存包、在关键时刻手动释放
- **MVP 不做**：手动拾取确认、自动/手动切换、跨局持久化背包

### 5.2 背包规则

| 规则 | 说明 |
|---|---|
| 槽位数量 | **3 格**（固定） |
| 拾取方式 | 飞行中碰撞道具 → **自动入包**（找第一个空槽） |
| 背包已满 | **不再拾取**；道具留在场上（可绕开）；可选闪烁「满」提示 |
| 同类堆叠 | 允许（如 3 格都可存筋斗云） |
| 使用时机 | **仅 `flying` 状态**；`ready`（起跳台）时槽位不可点 |
| 使用方式 | 点击槽位 / 键盘 **1·2·3** 对应槽 1·2·3 |
| 使用后 | 该槽清空，立即触发对应 Buff；Buff 期间可继续使用其他槽（见 §5.4） |
| 局内有效 | 背包随局结束清空，不跨局保留 |

### 5.3 MVP 道具（2 种）

| 道具 | 占位视觉 | 效果 | 持续 |
|---|---|---|---|
| **筋斗云** | 白色色块 + 「云」 | 无视重力，直线向上极速冲刺 | 3 秒 |
| **窜天猴** | 橙色色块 + 「猴」 | 超大向上冲量 → 缓降滑翔 | ~1s 爆发 + 滑翔 |

### 5.4 Buff 状态机（手动触发后）

| 规则 | 说明 |
|---|---|
| 触发来源 | 玩家从背包**主动使用** |
| 同类 Buff | **覆盖**（新使用重置计时） |
| 不同 Buff | 可并存（如筋斗云 + 后续再使用窜天猴 → 后者覆盖前者同类冲突时按覆盖规则） |
| 使用限制 | Buff 激活中**仍可使用**背包其他道具；同类则刷新 |

### 5.5 拾取与使用反馈

| 事件 | 视觉反馈 |
|---|---|
| 入包成功 | 道具消失 + 槽位亮起 + 短促缩放动画 |
| 背包满 | 碰撞无入包；可选槽位边框闪红 |
| 使用道具 | 槽位清空 + 激活 Buff 图标（右上）+ 粒子 |
| v1 音效 | 无（静音） |

### 5.6 道具生成

- 沿 Y 轴向上、X 随机偏移投放
- 垂直间距约 150～300px
- 两种道具等权重随机
- 被拾取后从场上移除；未拾取则保留（含背包满时）

### 5.7 后续 Phase B 扩展（MVP 不含）

| 道具 | 类型 | 效果 |
|---|---|---|
| 风火轮 | 正向 | 落地不结束，地面高速滑行后再结算（改为横向滑出） |
| 锦鲤 | 正向 | 好运模式：稀有道具概率×2；落地弹起一次 |
| 甲方改需求 | 负面 | 大幅减速 / 下拉 |
| 周一早高峰 | 负面 | 扣除高度（向下 impulse） |

## 6. 关卡与世界

### 6.1 镜头系统

- 角色锚定在屏幕**下方 30%～40%**
- 随高度上升，世界**向下滚动**
- 上方可见即将到达的道具

### 6.2 地形（MVP 简化）

| 元素 | 行为 |
|---|---|
| **起跳台** | 底部固定；开局站立；**唯一蓄力点** |
| **可选平台** | MVP 可不做；若做则仅作视觉/短暂落脚，**不可二次蓄力** |
| **虚空** | 落至关卡底部以下 → 结算 |
| **左右边界** | 软夹逼 |
| **顶部** | 无硬上限 |

### 6.3 边界（已确认）

| 边界 | 决定 |
|---|---|
| 左右 | 软夹逼 |
| 顶部 | 无硬上限 |
| 结算 | 触地（起跳高度以下）或落虚空 |

### 10.2 游戏主循环

```javascript
function gameLoop(timestamp) {
  const dt = Math.min((timestamp - lastTime) / 1000, 1 / 30);
  lastTime = timestamp;
  input.update();
  if (state === 'playing') {
    physics.update(dt);
    items.update(dt);
    world.update(dt);
    ui.update(dt);
  }
  render.clear();
  world.draw();
  items.draw();
  player.draw();
  ui.draw();
  requestAnimationFrame(gameLoop);
}
```

### 10.3 游戏状态机

```
title → ready（起跳台，可蓄力）→ flying → result → title
```

| 状态 | 说明 |
|---|---|
| `title` | 首屏 |
| `ready` | 起跳台，**可蓄力**（本局唯一窗口） |
| `flying` | 飞行中；可蹬风、拾取、使用道具；**不可再蓄力** |
| `result` | 结算 |
